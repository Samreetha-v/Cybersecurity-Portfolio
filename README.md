# 🔐 Cybersecurity Portfolio

A practical cybersecurity learning portfolio documenting my journey from Java Backend Development to Cybersecurity, with a focus on **Application Security, Product Security, SOC Analysis, and Bug Bounty**.

This repository contains my technical notes, hands-on labs, security testing exercises, tools practice, projects, and certifications.

---

**My goal:** To develop strong practical skills in Application Security and Product Security while gaining knowledge of SOC operations and ethical hacking.

---

## 🎯 Areas of Focus

| Domain | Learning Focus |

| Product Security | SSDLC, threat modelling, risk assessment |
